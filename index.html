Vercel (Khuyên Dùng)

1. Truy cập vercel.com (đăng nhập bằng GitHub/Google).
2. Kéo thả thư mục chứa file index.html này vào Vercel.
3. Nhận ngay link trực tuyến miễn phí dạng xhtools.vercel.app!

Tự động cấp SSL HTTPS miễn phí

GitHub Pages

1. Tạo một repository mới trên GitHub (VD: xh-tools-web).
2. Upload file index.html và file logo lên repo.
3. Vào Settings ➜ Pages ➜ Chọn Branch main và nhấn Save.

Địa chỉ: username.github.io/repo
♦

Netlify Drop

1. Truy cập app.netlify.com/drop.
2. Kéo toàn bộ thư mục chứa file vào ô tải lên.
3. Website sẽ hoạt động ngay lập tức sau 10 giây mà không cần tài khoản!
